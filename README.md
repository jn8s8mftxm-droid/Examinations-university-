# NEON SURVIVORS / ネオンサバイバーズ

**売れそうな完成度の高いブラウザサバイバルゲーム**

Vampire Survivors 系の自動攻撃サバイバルを、ネオンスタイルで美しく実装した完全無料プレイ可能なHTML5ゲームです。

## 特徴

- **中毒性の高いコアループ**: 自動攻撃 → 敵を倒す → XP取得 → レベルアップ強化 → さらに強くなる
- **美しいネオンビジュアル** + パーティクルエフェクト + 画面シェイク
- **8種類のアップグレード** (ダメージ、連射、移動速度、弾数増加、貫通、磁力、体力など)
- **難易度が時間とともに上昇** (敵の種類・速度・体力がスケール)
- **ローカルハイスコア保存**
- **PC & スマホ対応** (キーボード / マウス / タッチ)
- **効果音付き** (Web Audio API)
- **完全オフライン動作** (サーバー不要)

## 遊び方

1. `index.html` をブラウザで開くだけ
2. START GAME をクリック
3. **移動**: WASD / 矢印キー / マウスを押しながらドラッグ / タッチドラッグ
4. 自動で一番近い敵を狙って攻撃
5. 敵を倒して緑のXPオーブを集め、レベルアップ時に強化を選ぶ
6. できるだけ長く生き残ろう！
