# Focus Calm — 大学受験生のための落ち着いた学習アプリ

サイバーではなく、**勉強の合間に使うのにちょうどいい落ち着いたデザイン**に作り直しました。

## 追加・強化した機能

### ✅ 単語追加機能
- 英語・数学・理科・日本史・マイ単語に自分でカードを追加可能
- ローカルに保存されるのでずっと使えます

### ✅ 模試結果・偏差値推移
- 模試名・日付・偏差値・得点を記録
- 偏差値の折れ線グラフで推移を可視化
- 記録の削除も可能

### ✅ 志望校設定
- 大学名・学部・目標偏差値・優先度（第一志望など）を登録
- 最新の模試偏差値との差を自動表示

### ✅ PWA化
- `manifest.json` + Service Worker 対応
- スマホのブラウザで「ホーム画面に追加」するとアプリのように使えます
- オフラインでも動作します

### ✅ AIコーチング（ルールベース）
- 勉強時間・連続日数・科目バランス・模試と志望校の差を分析
- あなたに合ったアドバイスを表示
- 「アドバイスを更新」で再生成

## その他の基本機能
- ポモドーロタイマー（科目記録付き）
- 単語・公式帳（初期データ入り）
- 科目別進捗
- 今日の課題リスト
- 学習統計（7日間グラフなど）
- レベル・XP・連続記録

## 使い方
1. フォルダ内の `index.html` をブラウザで開く
2. またはスマホで開き「ホーム画面に追加」

データはすべて端末内に保存されます（サーバー不要）。
